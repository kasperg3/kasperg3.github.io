The AI handling Europe's data should run in Europe.

I build and run the machine learning systems behind commercial search at Colourbox — search that understands the actual content of images, video, audio and documents, hosted end to end on European infrastructure and kept inside EU jurisdiction. Before that, a PhD in multi-robot systems at the University of Southern Denmark on how one operator can command a swarm of drones, with a research stay at Carnegie Mellon's Robotics Institute.

Currently

My background is robotics. What that work taught me was the harder, less glamorous question behind any intelligent system: how do you get it running reliably, at scale, in production — and on infrastructure you actually control?

Search that understands content

Moving commercial search past keywords toward genuine semantic and multimodal understanding — models that read images, video, audio and documents rather than the metadata someone typed next to them.

Sovereign by architecture

The models powering all of it run on self-hosted, EU-based infrastructure, so customer data and AI processing never leave European jurisdiction. For the people Colourbox serves that is both a matter of trust and a real competitive advantage — and it means favouring right-sized, sovereign architecture over dependence on non-EU providers.

Robotics, still

I maintain the Python libraries from the PhD: decentralized multi-robot task allocation, coverage path planning, and the SAREnv benchmark, which other groups are now building on.

Python · Multi-agent

TrajAllocPy

Decentralized trajectory task allocation for multi-robot area coverage. A generalization of the consensus-based bundle algorithm that treats tasks as directed trajectories and optimizes traversal direction during allocation.

ICAR 2023CBBA
Python · Geospatial

TrajGenPy

Turns map features into flyable coverage tasks. Pulls geometry from OpenStreetMap, decomposes a region, and generates trajectories that prioritize the terrain where lost people are actually found — ditches, tree lines, water edges.

Coverage planningOSM
C++ · ESP-NOW · ROS 2

SwarmTalk

Decentralized UAV-to-UAV communication over 2.4 GHz using a connectionless protocol on commodity ESP hardware. UAVs join and leave without central governance or a-priori config, and it speaks ROS 2 directly.

ICUAS 2025COTS hardware
Multi-UAV · Planning

DDICP

Dynamic decentralized informative coverage planning. Multi-UAV area coverage that adapts the plan as information arrives, rather than committing to a sweep computed on the ground.

Real-world trials
 Benchmark · Dataset · Drones 2025

SAREnv

An open dataset and evaluation framework for informed wilderness search and rescue: 60 geospatial scenarios across four European environments, a lost-person probability model, baseline search strategies, and scoring metrics. Built so path-planning papers can finally be compared to each other — groups at Bristol are now extending it with student projects.

 Web · Scraping · Beer

HopDatabase

500+ hop varieties, scraped and normalized into something you can actually compare across — alpha acids, oil composition, substitutions. Built because choosing hops from vendor PDFs is miserable, and because I brew.
